# Getting help with p2a

- **Guides and docs:** [p2a.sh/guides](https://p2a.sh/guides). Start with [Get started](https://p2a.sh/guides/getting-started).
- **Common questions:** [p2a.sh/faq](https://p2a.sh/faq).
- **Bug in an SDK or other code:** open an issue in that repository.
- **Account, invite, or private-beta questions:** info@p2a.sh.
- **Security issues:** see [SECURITY.md](SECURITY.md). Please don't open a public issue.
